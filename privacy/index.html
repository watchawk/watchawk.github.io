Privacy policy

Mail Poll. Last updated 8 November 2026.

What Mail Poll accesses

When the owner of a Gmail account signs in and agrees, Mail Poll gets read-only access to that mailbox. It reads recent messages to check them against a list of keywords and sender names. This is the only purpose.

What is stored and sent

For a message that matches, Mail Poll sends the sender, the subject line, the time it was received and the text of the message as an alert. Attachments are not included. A short summary of matches (sender, subject and time only) is kept for a status page. Messages that do not match are not copied or sent anywhere, and are not recorded apart from an internal message ID kept so the same message is not checked twice.

Who receives it

The alert for a matching message is sent to the person who runs Mail Poll, through Telegram and through a private GitHub repository. These services only deliver and hold the alert, which includes the message text. The information is not sold, not used for advertising, and not shared with anyone else.

How long it is kept

Alerts stay in the private repository and in the Telegram chat until the person running Mail Poll deletes them. A summary file used for a status page, which holds sender, subject and time only, is kept for 7 days. Sign-in credentials are held as encrypted secrets in the private repository.

Your choices

The account owner can remove Mail Poll's access at any time at myaccount.google.com/permissions. After that, Mail Poll can no longer read the mailbox. To ask for stored alerts to be deleted, email watchawk@proton.me.

Google user data

Mail Poll's use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
